## v0.13.0 말의 페이지

말이 이 게임의 전부가 되도록 다시 다듬었습니다.

- **말로 만든 몸:** 최근에 건넨 말들이 손글씨로 윤곽선을 따라 흐릅니다(선 단계부터, 3D에서는 앞면 윤곽). 감정에 따라 흐르는 속도가 달라지고, 잠들면 멈춥니다.
- **말 조각:** 면 단계부터 먹인 말에서 떨어진 단어가 찢은 종이 조각처럼 화면에 떠 있습니다. 누르거나 페이지에게 끌어다 주면 먹고, 다른 조각 위로 끌면 두 말이 엮여 새 구절이 됩니다. 엮은 구절은 두 배로 든든하고 「말 사전」에 남습니다.
- **말로 대답하는 인생:** 올해의 이야기에 직접 한마디를 적습니다. 말에 담긴 낱말과 감정을 읽어 가장 가까운 길로 이어지고, 내 말로 답하면 능력이 1 더 오릅니다. 기존 선택지는 힌트로 남아 있어 눌러서 고를 수도 있습니다.
- **종이와 잉크:** 종이 질감, 번진 잉크 선, 손글씨(나눔펜), 테이프 붙인 인생 카드, 노트 같은 대화창, 도장 모양 알림.

글꼴은 Google Fonts(Gowun Batang, Nanum Pen Script)에서 불러옵니다. 오프라인이면 시스템 글꼴로 표시됩니다.

## 페이지의 인생

말과 선택으로 시간을 보내며 나만의 삶을 키웁니다. 처음 빈 화면을 유지하고, 2D 생명 단계(새로운 말 7개)부터 나이·직업·능력치가 화면에 나타납니다.

- **게임 속 나이:** 성장 점수 3점당 1살(새로운 말 하나는 2점), 한 해의 선택을 하면 추가로 1살. 오프라인 시간으로는 늙지 않습니다.
- **성장 시기:** 유년기(0~5), 배움기(6~12), 탐색기(13~17), 독립기(18~59), 여유기(60~).
- **능력치:** 이해력·상상력·친화력·활력. 말 먹이기와 연간 선택으로 오릅니다.
- **취미 8종:** 그림·독서·산책·친구 만나기·노래·퍼즐·정원 가꾸기·별 보기. 취미 연습은 한 해에 한 번, 연간 선택을 하면 다시 가능합니다.
- **상황 71종:** 공통 47종, 계절 전용 8종, 직업 전용 10종, 인연 전용 6종이 있습니다. 나이에 맞는 이야기마다 선택지가 3개이며, 직업 전용 이야기는 그 직업일 때만 찾아옵니다. 이미 본 이야기는 가능한 한 뒤로 미룹니다.
- **직업 10종:** 그림 작가·별 연구원·정원사·탐험가·이야기꾼·말 요리사·조각 기술자·마음 돌보미·음악가(상상력 30·친화력 20)·편지 배달부(활력 30·친화력 25).
- **직업 성장:** 18세 이상, 능력 조건을 충족한 직업을 선택합니다. 연간 선택마다 경험 1과 조각 수입을 얻고, 경험 5/12/25에 숙련/전문/거장이 됩니다.
- **직업 외형:** 안경·모자·배지 등 직업마다 다른 표시가 생깁니다.
- **이직·휴식:** 능력치는 유지하며 새 직업의 경험은 처음부터 시작합니다. 일을 내려놓고 자유롭게 지낼 수도 있습니다.
- **살아온 이야기:** 최근 60개 인생 기록을 저장하고, 화면에서는 최근 12개를 볼 수 있습니다.

나이는 120세부터 `120세+`로 표시하며 선택은 계속할 수 있습니다. 나이를 이유로 자동 사망하거나 직업을 잃지는 않습니다. 게임 속 학교·직업·수입은 현실을 재현하는 기준이 아닌 창작 규칙입니다.

**빠르게 확인:** 서로 다른 말 7개 먹이기 → 아래 「내 인생」 → 올해 상황에서 하나 선택 → 취미와 능력 키우기 → 18세에 「직업과 다음 길 보기」에서 직업 선택.

## 바로 실행하기

`npm start` 후 `http://127.0.0.1:8137` 을 열거나(포트 변경: `PORT=9000 npm start`), `public/index.html`을 Chrome에서 열면 됩니다. 서버와 API 키가 필요하지 않습니다. 저장을 안정적으로 이어가려면 배포한 주소에서 플레이하세요.

## GitHub → Vercel 배포

1. 이 폴더 안의 `public`, `vercel.json`, `README.md`, `CHANGELOG.md`, `package.json`, `scripts`를 GitHub 저장소의 최상위에 올립니다.
2. Vercel에서 새 프로젝트를 만들고 해당 GitHub 저장소를 가져옵니다.
3. 아래 설정으로 Deploy를 누릅니다. `vercel.json`에 기본값이 들어 있습니다.

| 항목 | 값 |
| --- | --- |
| Framework Preset | Other |
| Root Directory | 저장소 최상위 (`./`) |
| Build Command | 빈칸 |
| Install Command | 빈칸 |
| Output Directory | `public` |
| 환경 변수 / API 키 | 없음 |

`public` 폴더만 저장소 최상위에 풀어놓는 대신, 위의 폴더 구조를 그대로 유지하세요. 나중에 코드를 GitHub에 수정해 올리면 연결된 Vercel 프로젝트에서 배포됩니다.

공식 참고: [Vercel 정적 사이트 빌드 설정](https://vercel.com/docs/builds), [프로젝트 설정 파일](https://vercel.com/docs/project-configuration/vercel-json)

## Namecheap 도메인 연결

1. Vercel의 해당 프로젝트 → Settings → Domains에서 원하는 주소를 추가합니다.
2. Vercel이 **그 프로젝트에 표시한 DNS 레코드의 종류·이름·값**을 확인합니다.
3. Namecheap → Domain List → 도메인의 Manage → Advanced DNS → Host Records에서 필요한 레코드를 넣습니다.
4. Vercel에서 연결 상태가 유효해졌는지 확인한 뒤 HTTPS 주소로 접속합니다.

| 연결할 주소 예시 | Namecheap Host 예시 | 레코드 |
| --- | --- | --- |
| `example.com` | `@` | Vercel이 지정한 A 레코드와 값 |
| `pet.example.com` | `pet` | Vercel이 지정한 CNAME 레코드와 값 |
| `www.example.com` | `www` | Vercel이 지정한 CNAME 레코드와 값 |

DNS의 실제 값은 이 README의 예시에서 복사하지 말고 **Vercel 화면에 표시된 값**을 사용하세요. 같은 Host를 쓰는 기존 레코드가 있다면 충돌하는 항목만 조정합니다. 다른 서브도메인이나 메일용 MX/TXT 레코드는 별개입니다. 도메인의 네임서버가 Namecheap DNS가 아니라면 실제 DNS를 관리하는 곳에서 설정해야 합니다.

공식 참고: [Vercel 도메인 추가](https://vercel.com/docs/domains/working-with-domains/add-a-domain), [Namecheap CNAME 추가](https://www.namecheap.com/support/knowledgebase/article.aspx/9646/2237/how-to-create-a-cname-record-for-your-domain/), [Namecheap A 레코드 추가](https://www.namecheap.com/support/knowledgebase/article.aspx/319/2237/how-can-i-set-up-an-a-address-record-for-my-domain/)

## 이전 페이지의 저장 옮기기

브라우저 저장은 주소별로 구분됩니다. 기존 ChatGPT Site, Vercel 기본 주소, 새 도메인은 서로 다른 저장 공간입니다.

1. **이전 주소**에서 보관함 → 저장 파일 내려받기.
2. **새 최종 주소**에서 보관함 → 저장 파일 불러오기.
3. 이름과 성장 상태가 이어지는지 확인.

현재 로그인이나 서버 저장은 없습니다. 계정별·기기 간 자동 이어하기는 다음 개발 범위입니다. 최근 불러오기 또는 초기화 직전 상태는 보관함의 복구 버튼으로 되돌릴 수 있습니다. 브라우저 데이터를 지우면 이 복구 기록도 지워집니다.

## 플레이

- 서로 다른 말을 먹이면 성장하고 조각을 얻습니다.
- 점과 선도 만지거나 끌 수 있습니다.
- 면에 색이 차고 눈과 입이 생깁니다.
- 2D 생명 단계에서 놀이와 꾸미기가 열립니다.
- 3D 단계에서 드래그 또는 방향키로 회전합니다. Home은 기본 각도로 복원합니다.
- 「이 느낌이 맞아?」로 마지막 말의 감정을 직접 고칩니다. 같은 표현은 다음에도 고친 감정으로 받습니다.
- 위의 단계 이름을 누르면 성장 기록을 봅니다. 성장 카드 SVG도 내려받을 수 있습니다.
- 장식 배치 중 방향키로 이동, Shift+방향키로 크게 이동, Delete로 재료 일부를 돌려받습니다.

## 성장 조정

기준은 성장 점수로 적혀 있습니다(`public/dimensions.js`의 `DIMENSION_STAGES`). 새로운 말 하나가 주는 점수는 `public/game.js`의 `GROWTH_PER_WORD`(현재 2) 하나로 정하므로, 전체 속도는 이 값만 바꾸면 됩니다.

| 단계 | 성장 점수 | 새로운 말 (현재) |
| --- | ---: |
| 점 | 1 | 1 |
| 선 | 3 | 2 |
| 닫히는 윤곽 | 6 | 3 |
| 면 | 9 | 5 |
| 2D 생명 | 14 | 7 |
| 3D 입체 | 24 | 12 |

표정은 성장 점수 11점에 눈, 12점에 입이 나타납니다(현재 6번째 말에 함께). 기준을 크게 바꾸면 같은 파일의 표시 조건과 `upgrade.js`의 놀이 해금 조건도 함께 조정해야 합니다.

## 변신 사전 다시 만들기

`public/shapes.js`는 직접 고치지 않고 생성합니다. 유니코드 CLDR 한국어 주석(`cldr-annotations-full`의 `annotations/ko/annotations.json`)과 `emoji-test.txt`(unicode.org/Public/emoji)를 내려받은 뒤:

```
node scripts/build-shapes.cjs <annotations.json 경로> <emoji-test.txt 경로>
```

잘못 잡히는 일상어는 스크립트의 `STOP`, 꼭 필요한 단어는 `OVERRIDES`에 넣습니다. 데이터 출처: Unicode CLDR / Unicode Emoji (Unicode License v3).

## 검사와 현재 한계

Node.js가 설치되어 있다면 저장소 최상위에서 `node scripts/check.cjs` 또는 `npm test`로 검사를 실행할 수 있습니다. 외부 패키지 설치는 필요하지 않습니다.

차원 성장, 입체 좌표, 저장과 복구, 감정 교정, 반복 보상 제한, 나이별 사건, 취미, 직업 조건·수입·승진과 구버전 저장 호환을 코드로 확인했습니다. 실제 브라우저에서의 터치·드래그·애니메이션과 실제 Vercel 배포는 추가 확인이 필요합니다.

감정은 AI가 아닌 단어 규칙과 사용자의 교정 기록으로 해석합니다. 복잡한 문장이나 반어법은 잘못 읽을 수 있습니다. 중복 방지에는 최근 5,000개의 정규화된 표현을 기억하며, 교정은 최근 100개 표현을 기억합니다. 오래된 버전의 최근 대화 밖에 있는 말은 역으로 복원할 수 없습니다.

3D는 같은 평면에 두께를 붙인 기하를 SVG에 원근 투영하는 방식입니다. 자유로운 입체 회전은 가능하지만, 전용 3D 엔진이나 물리 시뮬레이션은 사용하지 않습니다. 표정의 원근 처리는 간단한 근사입니다.

대화와 저장은 브라우저 안에 머뭅니다. 외부 요청은 글꼴 파일(Google Fonts)뿐이며, 게임 코드에는 서버 전송, 분석 SDK, API 키, 인증 토큰 또는 기존 배포의 프로젝트 식별자가 들어 있지 않습니다.
